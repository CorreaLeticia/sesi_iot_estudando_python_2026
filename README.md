# Estudando Python

Lista de exercícios de Python resolvida em aula do SESI SENAI no curso Técnico em Desenvolvimento de Sistemas.

## Tecnologias

- Python
- VS Code

## Exercícios

1. Média de três números
2. Conversor de temperatura
3. Identificação de número par ou ímpar
4. Cálculo de fatorial
5. Verificador de ano bissexto
6. Verificação de número positivo ou negativo
7. Comparação de dois números
8. Verificação de idade
9. Classificação de triângulos

## Para testar

É necessário ter o Python instalado no computador.

Abra o terminal na pasta do projeto e execute o arquivo desejado utilizando o comando:

```bash
python nome_arquivo.py
```

Por exemplo:

```bash
python exercicio01_media.py
```
